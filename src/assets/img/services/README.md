# Services page photo mockups

Drop one image per discipline here. The services page picks them up automatically
and shows the photo (with the clip reveal + a gentle parallax) instead of the
code-built visual. Remove a file to go back to the code visual for that section.

| File name (any of .jpg .jpeg .png .webp) | Section |
|---|---|
| `web.jpg`    | Websites (laptop + phone) |
| `brand.jpg`  | Brand identity (brand board) |
| `print.jpg`  | Print (brochure, cards, competition board) |
| `social.jpg` | Social & marketing (Instagram + newsletter) |

Best results: 4:3 landscape, at least 2048 × 1536, same light and background
across the four (see the prompts in the chat).
